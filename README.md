
# Slash Rain
한컴타자 '산성비' 방식의 타자 게임입니다. 하늘에서 Claude Code 슬래시 명령어가 내려오면, 바닥에 닿기 전에 똑같이 입력하고 Enter를 눌러 없애세요.

플레이: **https://ahin99.github.io/Slash-Rain/**
- 체력 10칸. 명령어가 바닥에 닿을 때마다 1칸씩 줄어듭니다.
- 15개를 맞힐 때마다 단계가 올라가고 속도가 빨라집니다 (최대 12단계).
- ★ 금색 = 점수 3배 · ❄ 하늘색 = 3초 정지 · + 초록 = 체력 회복 · ⚡ 보라 = 화면 전체 제거
- 맞힌 명령어와 놓친 명령어의 한국어 설명을 보여줍니다.
- Esc로 일시정지합니다.
